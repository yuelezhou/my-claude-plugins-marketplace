# Hello Greeting Plugin

一个简单的 Claude Code 插件，支持 `/greeting` 命令。

## 功能

- 使用 `/greeting` 命令获取多种语言的问候语
- 支持 10+ 种语言的问候
- 友好的欢迎消息

## 安装

将此插件添加到你的 `.claude-plugin/marketplace.json`：

```json
{
  "name": "hello-greeting",
  "description": "简单的问候插件 - 支持多种语言的问候语",
  "path": "plugins/hello-greeting"
}
```

## 使用

```
/greeting
```

## 示例输出

```
🌟 你好！今天是一个美好的日子！
🌟 Hello! Hope you have a great day!
🌟 こんにちは！素敵な一日を！
```
