- **MiniMax：无市场层（源码级确认）**，聚合只能落成**物理拷贝**到 `~/.minimax/plugins/<名>/`（drop-in 免登记自动启用）；其 UI 导入通道本身也支持任意 GitHub 插件 URL（`/tree/<ref>/plugins/<名>`），说明「外部 Claude 形态插件」与 MiniMax 兼容性取决于插件本身（见 docs/plugin-compatibility.md 矩阵：含 agents/commands 的插件在 MiniMax 降级）
- **分发基建复用**：plugin-hub#01 的 link-plugins 机制（Claude/ZCode 市场注册 + MiniMax 拷贝）可直接服务外部插件，无需另起炉灶
