# 基础词判定：集合相交判据，隐藏集=中考/高考/CET4，CET6 为边界档

word-frequency 的生词判定要回答"哪些词默认不进生词表"。词表数据里大量词同时挂在低
端词表（中考/高考/CET4-6）与高端词表（考研/雅思/托福/GRE）——levels.tsv 18074 词中
5516 个含中考/高考/CET4 标签。判据在两个版本间翻转过一次：v1.2.0 采用**最高等级判据**
（只看最高档，CET4+考研 双标的 abandon 因最高档是考研而显示，理由是"它们是真难词"），
但用户实测台词本报告后推翻：生词表仍被 bang/god/hi/hello/physics 这类明显已学的词占满。
用户的判定哲学是**低端词表收录本身就是"学过"的证据**——中学/CET4 词表收了的词，哪怕
它同时在雅思/GRE 表里，也大概率学过；而最低只到 CET6 的词**要显示**——可能学得不牢固，
需要露出来复习。决定：基础词判定用**集合相交**——词的等级集合与隐藏集
{中考, 高考, CET4} 相交即隐藏；CET6 不在隐藏集。实测生活大爆炸 S01 台词本：生词表
2775 → 1739（隐藏 1036），cute/costume/premise/molecular 等 CET6 边界词保留。

## Considered Options

- 最高等级判据（v1.2.0 曾采用）：abandon 类双标词显示——否决，用户实测生词表被已学词
  占满；"真难词"论点与"低端收录=学过"的直觉冲突时，用户选后者
- 相交判据且 CET6 入隐藏集（隐藏集四档）：cute/costume/premise 这类边界词也消失——
  否决，用户明确说 CET6 词"可能学得不牢固"，要露出来
- 加 `--basic-level` 可调参数把口径交给用户：否决，过度设计——过滤档位直接改默认值
  （沿用 v1.2.0 的既定偏好）

## Consequences

- abandon / abstract / absorb 这类 CET4 与进阶档双标的词从生词表消失；要再看它们，
  走 known_words.txt 之外的路径不存在——这是接受的代价，勿再以"真难词"为由翻回
- CET6-only 词回归生词表；对"只想看六级以上"的用户它们是复习档而非生词，报告里的
  等级 chip 可按 CET6 筛选
- 词组页不加基础词过滤、词组等级 chip 按"最难词"标注的既定决定不变
- `filtered_basic` 计数含义随判据变化；测试以 premise（CET6 边界显示）与
  abandon（双标隐藏）双哨兵锁定口径
